Under the Hood: Network Protocol Stack

1. Transport Layer: TCP 3-Way Handshake (SYN → SYN-ACK → ACK) establishes connection on Port 8080.

2. Application Layer: The web browser sends an ASCII HTTP/1.1 request formatted with CRLF line breaks.

3. Parsing Engine: Our socket server tokenizes the request line, identifies MIME types, and streams binary bytes.
